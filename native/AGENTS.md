# Native mobile apps

The native apps are paid Toyboxes single-player games. All circuits, teams, cars and reference times are fictional. No real circuit outlines, sporting marks, team liveries or network services may enter either app bundle.

Use Kotlin with Android Canvas and SwiftUI with iOS Canvas. The shared C++ core is the timing authority. Keep the draw, tyre, race, result, retry loop playable with touch. Do not replace it with a WebView.

Preserve deterministic timing. Build with floating-point contraction and fast math disabled. Increment the native SIM_VERSION whenever a change can invalidate saved lap times, and update both persistence readers. The original web simulator has its own separate version.

Circuits are generated by `node native/scripts/generate-circuits.mjs`. Change that original authoring source, then regenerate. Do not import the web game's circuit data into native apps.

Before release: run the shared core tests, native Android touch tests, Android lint and release build, iOS simulator tests, and `node native/scripts/check-release.mjs`. Capture native screenshots. A source scan or unit test does not substitute for platform playtesting.

Use the existing retained signing identities. Do not create, replace, copy, export or disclose keys or passwords. Leave the paid price unset until supplied by the user. Report store submission separately from store approval and publication.

Follow the root rules for plain copy, secrets and punctuation. Rules about real circuits and sporting regulations in the original web simulator do not apply to this fictional native game.
